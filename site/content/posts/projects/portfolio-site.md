## 개요

- **기간**: 2026.11.01 ~ 2026.11
- **상태**: 완료
- **형태**: 개인 프로젝트 (초급프로젝트 수업 과제)

## 목표

웹의 기본 구성인 HTML, CSS, JavaScript를 직접 고쳐 보면서 웹 페이지가 어떤 구조로 만들어지는지 이해하는 것이 목표였습니다.
시작할 때는 Git을 조금 아는 것 말고는 웹 개발 경험이 거의 없었고, AI와 검색으로 하나씩 배우면서 만들었습니다.

## 역할

기획부터 디자인 수정, 콘텐츠 작성, 배포까지 **혼자 진행한 개인 프로젝트**입니다.
일부 구현은 AI의 도움을 받았으며, 도움 받은 부분과 출처는 보고서에 정리했습니다.

## 진행 과정과 선택 이유

1. **테마 선택**: Hugo 테마 중 Mana 테마를 골랐습니다.
   독특한 디자인이 먼저 눈에 들어왔고, 원하는 구성이 이미 완성된 템플릿에 내용만 채우기보다는 일부라도 직접 만들어 보고 싶었습니다.
   그래서 일부러 기획한 구성과 조금 다른 테마를 선택했습니다.
2. **배포 설정**: GitHub Actions로 main에 push하면 GitHub Pages에 자동 배포되도록 구성했습니다.
3. **홈 구성**: 홈을 한 페이지로 만들고 About · Projects · Experience · Blog 섹션으로 나눴습니다.
   포트폴리오라면 스크롤만으로 전체를 간략하게 파악할 수 있어야 한다고 생각했습니다.
4. **About 디자인**: 처음에는 카드 형태였지만, 글을 클릭하기 전에 한눈에 보기 편하도록 사진과 글을 나란히 두는 형태로 바꿨습니다.
5. **작업 방식**: 기능마다 브랜치를 만들고 Pull Request로 main에 합쳤습니다. 수업에서 배운 Git 작업 흐름을 실제로 적용해 보고 싶었습니다.

## 배운 점

- **검색 기능 문제**: 검색 버튼은 있었지만 검색이 되지 않았습니다. 테마의 검색은 `index.json` 파일을 읽는데, 이 파일을 만들라는 설정(`outputs`)이 빠져 있었습니다. 설정 한 줄로 해결하면서, 화면의 기능이 설정 파일과 어떻게 연결되는지 알게 되었습니다.
- **Hugo 템플릿과 경로**: Go 템플릿 문법이 익숙하지 않아 변수를 다루는 데 어려움이 있었습니다. 또 사이트가 `/Portfolio_Practice/` 하위 경로에 배포되기 때문에, 링크를 `/`로 시작하면 홈이 아닌 도메인 최상위로 가는 문제를 겪었습니다. 이를 고치며 배포 경로를 고려해 링크를 만드는 법을 익혔습니다.

## 한계와 다음 개선 방향

- **블로그 구성**: 지금은 테마의 기본 블로그 목록과 태그 필터를 사용합니다. 글을 폴더 단위로 나누고 폴더 내비게이션을 만들어 더 깔끔하게 구성하고 싶었지만, 현재 실력으로는 어려워 다음 과제로 남겼습니다.
- **문의 기능**: Contact에서 사이트 안에서 바로 문의를 보낼 수 있게 하고 싶습니다. GitHub Pages는 미리 만들어 둔 파일만 보여주는 정적 호스팅이라, 방문자가 입력한 내용을 받아 저장하거나 메일로 보내 줄 서버가 없습니다. 이를 구현하려면 직접 서버(백엔드)를 만들거나 외부 폼 서비스를 연결해야 하고, 스팸 방지도 필요합니다. 지금은 이메일 링크로 대신했고, 백엔드를 공부한 뒤 추가할 계획입니다.

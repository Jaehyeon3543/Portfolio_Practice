About Me

저는 웹과 게임에 관심이 있습니다. 둘 다 매일 쓰고 즐기는 분야라, 화면 뒤에서 어떻게 만들어지는지 자연스럽게 궁금해졌습니다. 개발을 막 시작한 지금은 가장 익숙한 분야부터 탄탄히 다지고, 그 위에서 관심의 폭을 넓혀 가려고 합니다.

지금 목표는 나만의 웹 서비스를 직접 만들어 배포하는 것입니다. 이번 겨울방학에는 AI 사용을 최소화하고 작은 웹 서비스를 처음부터 끝까지 만들어 보며 서비스가 만들어지는 과정을 익히고, 그다음에는 새로운 서비스를 만들어 실제로 배포할 계획입니다. 공모전이나 대회에 나가 수상하는 것도 목표입니다.

이 포트폴리오 사이트를 만들며 처음 사용해 본 기술들입니다:

  • Hugo - 포트폴리오 사이트 제작
  • HTML / CSS - 웹 페이지 디자인 및 구현
  • Markdown - 콘텐츠 작성
  • Git - 버전 관리
  • GitHub Actions - 지속적 통합
  • GitHub Pages - 웹사이트 호스팅

예를 들어 Git으로는 기능마다 브랜치를 만들고 Pull Request로 main에 합치며 작업했고, GitHub Actions로 main에 push하면 사이트가 자동으로 빌드·배포되도록 구성했습니다.
